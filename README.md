# Lily Shaker — UX/UI Portfolio

Static portfolio site for Lily Shaker, UX/UI designer. It's a lawyer's journey into UX design.

## Pages

- `index.html` — home and project list (TravlMate, TruNorth, TherapEze, Shoniz Chocolate)
- `about.html` — about Lily
- `contact.html` — get in touch
- `travlmate.html`, `trunorth.html`, `therapeze.html`, `shoniz-chocolate.html` — case studies

## Structure

```
assets/css/style.css   styles (palette and type from the original theme)
assets/js/main.js      menu, sliders, lightbox, contact form
assets/img/            optimized WebP images
assets/Lily_Shaker_Resume.pdf
```

No build step is needed. To publish with GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

Fonts: Gambetta (Fontshare) and Inter (Google Fonts).
